# 第7章と同じEmployee・Department・Jobを扱うAPI
# Codinable では実行対象「gradle:bootRun」で起動する（demo プロファイル＝インメモリ DB が既定で使われる）。
# Codinable のターミナル（Git Bash）で次の curl を実行する。
# 以下のcurl例はGit Bash用。8080が使用中なら起動時に--server.portを変更する。

### 部署マスタ（4件）と役職マスタ（4件）
curl -i http://127.0.0.1:8080/departments
curl -i http://127.0.0.1:8080/jobs

### 社員を1件取得。versionを確認する。
curl -i http://127.0.0.1:8080/employees/10001

### 社員一覧（content、totalPages、totalElements）。1ページ5件。
curl -i 'http://127.0.0.1:8080/employees?page=1'
curl -i 'http://127.0.0.1:8080/employees?page=2'

### 部署・役職・月給範囲でAND検索
curl -i 'http://127.0.0.1:8080/employees?departmentId=3&jobId=1&salaryFrom=250000&salaryTo=300000'

### 氏名の部分一致で検索（日本語などはURLエンコードして送る）
curl -i --get http://127.0.0.1:8080/employees --data-urlencode 'keyword=Alice'

### 既存教材の月給下限検索（こちらは配列）
curl -i 'http://127.0.0.1:8080/employees/query_by_salary?lowerSalary=500000'

### 社員を登録。201とLocation、採番されたemployeeIdを確認する。
curl -i -X POST http://127.0.0.1:8080/employees \
  -H 'Content-Type: application/json' \
  -d '{"employeeName":"Walter","departmentId":3,"jobId":1,"salary":230000,"entranceDate":"2018-04-01"}'

### 初期状態で最初に登録した社員はID=10017、version=0。
### 繰り返す場合は、直前の登録応答にあるIDとversionへ置き換える。
curl -i -X PUT http://127.0.0.1:8080/employees/10017 \
  -H 'Content-Type: application/json' \
  -d '{"employeeName":"Walter","departmentId":2,"jobId":2,"salary":260000,"entranceDate":"2018-04-01","version":0}'

### 同じPUTをversion=0のまま再実行すると409（更新競合）。
### GETでversion=1になっていることを確認する。
curl -i http://127.0.0.1:8080/employees/10017

### 論理削除。成功は204で本文なし。再取得は404。
curl -i -X DELETE http://127.0.0.1:8080/employees/10017
curl -i http://127.0.0.1:8080/employees/10017

### 存在しない部署は400
curl -i -X POST http://127.0.0.1:8080/employees \
  -H 'Content-Type: application/json' \
  -d '{"employeeName":"Wendy","departmentId":999,"jobId":1,"salary":230000,"entranceDate":"2018-04-01"}'
