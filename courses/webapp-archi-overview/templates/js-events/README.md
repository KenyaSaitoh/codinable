# js-events — イベントを受け取って反応する

チャプター 3.2「JavaScriptによるWebページ振る舞い制御」の演習です。
ユーザーの操作は「イベント」として JavaScript に届きます。
`addEventListener` で登録したイベントが、発生した順に画面右の記録欄へ積まれていきます。

## 主なファイル

- `index.html` … 操作する部品（ボタン・入力欄・選択欄（select）・マウスを乗せる箱）と記録欄
- `app.js` … イベントの登録。`要素.addEventListener('イベント名', 関数)` の形がくり返し出てきます
- `style.css` … 見た目。マウスを乗せたときの `.hovered` の装飾もここにあります

## 動かし方

1. ▶ アプリ実行を押すと内蔵の静的サーバーが起動し、出力欄の「🌐 プレビュー」タブにページが開きます
2. ボタンを押す、文字を打つ、選び直す、入力欄の中と外をクリックする、キーを押す、マウスを乗せる……を試し、
   記録欄に出るイベント名と要素を見ます。記録は「消す」で空にできます

## 見どころ

- `click`（押されたとき）と、押した回数のカウント
- `input`（1 文字ごと）と `change`（値が確定したとき）の違い。同じ入力欄に両方を登録してある
- `focus` / `blur` でフォーカスの出入りに合わせて枠の色を変える
- `keydown` の `event.key` に押したキーの名前が入る
- `mouseover` / `mouseout` でクラスを付け外しする
- `event.type`（イベント名）と `event.target`（イベントが起きた要素）
- `load` はページ全体の出来事なので `window` に登録する（記録欄の最初の 1 行）
