セマンティック要素とは

div はそれ自体に意味を持たない汎用の入れ物である。 header や main といったセマンティック要素に置き換えると、 Web ブラウザや検索エンジン、スクリーンリーダーが領域の役割を読み取れるようになる。

div と span の違い

div はブロック要素で、横幅いっぱいに広がり前後が改行される。 span はインライン要素で、文章の流れの中に収まる。
