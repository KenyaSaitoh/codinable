# html-semantic — セマンティック要素でページを組む

チャプター 3.1「HTMLによるWeb構造定義」の演習です。
`header` / `nav` / `main` / `article` / `section` / `aside` / `footer` で組んだブログ風のページです。
同じ見た目は `div` だけでも組めますが、セマンティック要素ならタグ名から領域の役割が読み取れます。

## 主なファイル

- `index.html` … ページ本体。各領域と、`div` / `span` の比較、アクセシビリティ用の属性が入っています
- `outline.css` … どこがどの領域かを見えるようにするだけの CSS（破線の枠と `<header>` などのラベルを付ける）。読み流してかまいません
- `menu-icon.svg` … アイコンだけのボタンに使っている画像

## 動かし方

1. ▶ アプリ実行を押すと内蔵の静的サーバーが起動し、出力欄の「🌐 プレビュー」タブにページが開きます
2. 領域を入れ替えたり増やしたりして保存し、プレビューを再読み込みしてラベル付きの枠がどう変わるかを見ます

## 見どころ

- 各領域の役割: `header`（ヘッダー）、`nav`（ナビゲーションリンクのまとまり）、
  `main`（主要コンテンツ。1 ページに 1 つ）、`article`（単体で意味が通る記事）、
  `section`（テーマごとのまとまり）、`aside`（補足・サイドバー）、`footer`（フッター）
- `div` はブロック要素で縦に並び、`span` はインライン要素で文章の流れの中に横に並ぶ
- アイコンだけのボタンには `aria-label` で読み上げ用のラベルを付け、装飾の画像は `alt=""` にする
- `aria-live="polite"` の領域は、JavaScript で中身を差し替えたときにスクリーンリーダーが読み上げる
  （差し替えの実際は 3.2 の DOM 操作で扱います）
