# css-layout — Flexbox と Grid でレイアウトする

チャプター 3.3「CSSによるWebページ修飾」の演習です。
ページの骨組みを組む 2 つの道具を、向きの数で使い分けます。

- Flexbox … 1 方向（横一列 / 縦一列）に並べる。ナビゲーション、カードの横並び
- Grid … 行と列の 2 次元のマス目に置く。ページ全体のレイアウト

## 主なファイル

- `index.html` … ナビゲーションバー（Flexbox）と、サイドバー・本文・フッターのページ全体（Grid）
- `style.css` … 「Flexbox: 1 方向に並べる」「Grid: 行と列の 2 次元」の 2 つに分けてあります

## 動かし方

1. ▶ アプリ実行を押すと内蔵の静的サーバーが起動し、出力欄の「🌐 プレビュー」タブにページが開きます
2. プレビューとエディタの境目をドラッグして幅を変え、カードが折り返す様子を見ます
3. `style.css` の値を変えて保存し、プレビューを再読み込みして並びの変化を見ます

## 見どころ

- ナビゲーションバー: `display: flex` で横一列、`justify-content: space-between` で両端に寄せ、
  `align-items: center` で縦の中央にそろえ、`gap` で間隔をあける
- `justify-content` の値（`flex-start` / `center` / `space-between` / `space-around`）による違い
- `flex: 1` と `flex: 2` で、余った幅を 1:2 の比で分ける
- カードの横並びは `flex-wrap: wrap` と `flex: 1 1 160px` で、入りきらなければ次の行へ回る
- ページ全体の Grid: 1 列目 200px 固定・2 列目は残り全部（`1fr`）。フッターは `grid-column: 1 / 3` で 2 列ぶんを占める
- マス目の例: `repeat(3, 1fr)` で均等 3 列。`.wide` のセルは 2 列分を占める
