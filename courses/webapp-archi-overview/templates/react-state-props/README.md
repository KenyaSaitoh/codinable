# react-state-props — State と Props の単方向データフロー

チャプター 10.1.4「データの流れと状態管理（StateとProps）」の演習です。
親（`App`）が `useState` で一覧を持ち、子（`UserList`）へ Props と削除用のコールバックを渡します。

## 主なファイル

| ファイル | 中身 |
|---|---|
| `src/UserList.tsx` | 主役。子。Props の一覧を表示し、削除したいときは親から受け取った `onDelete` を呼ぶ |
| `src/App.tsx` | 親。`useState` でカウンターとユーザーの一覧を持ち、setter で更新する |

## 動かし方

1. ▶ アプリ実行を押す。初回だけ依存パッケージを自動で入れてから Vite の開発サーバー
   （`http://127.0.0.1:5173`）を起動し、プレビュータブが開く（初回は数分かかることがある）
2. 画面を操作する。ソースを書き換えて保存すると、Vite がすぐに画面へ反映する
3. 終わったら「停止」で止める

## 見どころ

- カウンターの「-1」「+1」で State が変わると、React が画面を描き直す
- 「削除」は子が `onDelete(id)` を呼び、親の State が変わって一覧が描き直される
  （データは親 → 子へ流れ、変更は関数で親へ知らせる）
- 「初期状態へ戻す」で State を最初の 3 件に戻せる
