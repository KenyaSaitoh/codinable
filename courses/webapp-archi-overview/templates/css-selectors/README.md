# css-selectors — セレクタで対象を選び、色と文字を変える

チャプター 3.3「CSSによるWebページ修飾」の最初の演習です。
CSS の 3 つの書き方と、要素・クラス・ID・子孫・擬似クラス・属性の各セレクタ、
色の書き方、フォントと背景のプロパティ、詳細度と継承を 1 ページにまとめてあります。

## 主なファイル

- `index.html` … CSS の 3 つの書き方がすべて入ったページ
  - ① 外部スタイルシート（`style.css` を `link` で読み込む）… 実務で使うのはこれ
  - ② 内部スタイルシート（`head` の中の `style` タグ）
  - ③ インラインスタイル（要素の `style` 属性）
- `style.css` … セレクタの種類ごとに区切りコメントを付けてあります

## 動かし方

1. ▶ アプリ実行を押すと内蔵の静的サーバーが起動し、出力欄の「🌐 プレビュー」タブにページが開きます
2. `style.css` を書き換えて保存し、プレビューを再読み込みすると表示が変わります

## 見どころ

- 要素セレクタ（`body` / `p` / `h1`）、クラスセレクタ（`.note` / `.card`）、
  子孫セレクタ（`.card p` は「.card の中の p」だけ）
- 擬似クラス（`a:hover`、`button:disabled`）と属性セレクタ（`input[type="text"]`、`input[disabled]`）
- 詳細度: 「詳細度」の段落には `p`・`.note`・`#priority` の 3 つが当たっていて、ID セレクタが勝って緑になる。
  `style.css` の `#priority` の行を消すと `.note` の色に戻る
- 継承: `.inherit-demo` に指定した色とフォントが、何も指定していない子の `p` に引き継がれる
- 色の指定形式: カラーネーム（`navy`）、16 進数（`#2f6feb` と省略形 `#f60`）、`rgb()`、透明度付きの `rgba()`
