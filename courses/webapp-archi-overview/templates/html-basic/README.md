# html-basic — HTMLの基本構造

チャプター 3.1「HTMLによるWeb構造定義」の最初の演習です。
CSS も JavaScript も読み込んでいない、HTML だけのページです。
見えているのは、Web ブラウザが素の HTML に付ける既定の見た目です。

## 主なファイル

- `index.html` … ページ本体。見出し（h1〜h3）・段落・画像・リンク・id / class 属性が入っています
- `logo.svg` … `img` タグで表示している画像

## 動かし方

1. ▶ アプリ実行を押すと内蔵の静的サーバーが起動し、出力欄の「🌐 プレビュー」タブにページが開きます
2. `index.html` のタグや文字を書き換えて保存し、プレビューを再読み込みすると表示が変わります

## 見どころ

- `head` の中の `meta charset`・`meta viewport`・`title`（タブに出るページ名）の役割
- 見出しは `h1` から `h6` まで。数字が小さいほど上位
- 段落（`p`）の中の改行（`br`）と、段落そのものを分ける違い
- `img` は閉じタグを書かず、`alt` に代替テキストを書く。`logo.svg` の名前を変えると alt の文字が出る
- リンクの種類: 別タブで開く外部リンク（`target="_blank"` と `rel`）、
  ページ内リンク（`href="#contact"` → `id="contact"` の見出しへ移動）、`mailto:` のリンク
- 最後の段落の `id="unique-paragraph"` と `class="note"` は、見た目は変わりませんが、
  3.2 の JavaScript と 3.3 の CSS から要素を指し示すのに使います
