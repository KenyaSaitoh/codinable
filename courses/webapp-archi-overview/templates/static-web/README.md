# static-web — HTML・CSS・JavaScript を組み合わせて 1 つの画面を作る

チャプター 3.1〜3.3 のまとめの演習です。
構造は HTML、装飾は CSS、振る舞いは JavaScript と、3 つのファイルで役割を分けた名簿管理ページです。
10 章の React 版（react-spa）が同じ題材なので、あとで見比べられます。

## 主なファイル

- `index.html` … 構造。登録フォームと一覧の表（行は空で、`app.js` が組み立てる）
- `style.css` … 装飾。HTML には `style` 属性を書かず、色は `:root` の CSS 変数にまとめてある
- `app.js` … 振る舞い。名簿のデータ（`people`）を持ち、変わったら画面を描き直す

## 動かし方

1. ▶ アプリ実行を押すと内蔵の静的サーバーが起動し、出力欄の「🌐 プレビュー」タブにページが開きます。
   最初は Alice と Bob の 2 件が並びます
2. 名前と部署を入れて「追加する」を押すと一覧に行が増え、件数とメッセージが更新されます
3. 各行の「削除」を押すと、その行が消えます
4. データは JavaScript の配列にあるだけなので、プレビューを再読み込みすると最初の 2 件に戻ります

## 見どころ

- `submit` を受けて `event.preventDefault()` で既定の送信（ページ再読み込み）を止め、JavaScript で処理する
- データ（`people`）を正として持ち、追加・削除のたびに `render()` で表を組み立て直す
  「状態 → 描画」の流れ。これはチャプター 10 の React でも同じ考え方になる
- 3 つのファイルのどれか 1 つだけを書き換えると、構造・見た目・振る舞いのどれが変わるかが分かれていることを確かめられる
