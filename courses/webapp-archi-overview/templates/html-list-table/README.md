# html-list-table — リストとテーブル

チャプター 3.1「HTMLによるWeb構造定義」の演習です。
「並んだデータ」を表す 2 つのタグ、箇条書き（`ul` / `ol`）と表（`table`）の書き方を見ます。
CSS は読み込んでいないので、見えている線や記号はすべて Web ブラウザの既定表示です。

## 主なファイル

- `index.html` … 社員名簿のページ。リスト 3 種類とテーブル 2 種類が入っています

## 動かし方

1. ▶ アプリ実行を押すと内蔵の静的サーバーが起動し、出力欄の「🌐 プレビュー」タブにページが開きます
2. `index.html` に行や項目を足して保存し、プレビューを再読み込みしてどこに何が出るかを確かめます

## 見どころ

- `ul`（順序なし・記号が付く）と `ol`（順序付き・番号が付く）の違い
- 入れ子のリスト: `li` の中に `ul` を入れると階層になる（閉じる位置に注意）
- テーブルの部品: `tr` が行、`th` が見出しセル、`td` がデータセル
- `thead`（見出し部）と `tbody`（本体）に分けると、行の役割が読み取れる
- 2 つ目の表は見出しを左側に置き、`th scope="row"` で「行の見出し」であることを示している
- `border="1"` は枠線を出すための古い書き方で、本来は CSS の仕事（3.3 で `border` プロパティとして扱う）
