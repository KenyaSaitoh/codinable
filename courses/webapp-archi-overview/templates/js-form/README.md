# js-form — JavaScript でフォームを扱う

チャプター 3.2「JavaScriptによるWebページ振る舞い制御」の演習です。
ユーザー登録フォームの `submit` を JavaScript で受け取り、`event.preventDefault()` でページ遷移を止めてから
自分で検証・値の取り出しを行います。HTML の検証属性（`required` など）も併せて働きます。

## 主なファイル

- `index.html` … フォーム本体。`action` を書かず、送信を JavaScript が受け取ります
- `app.js` … 入力中の検証、送信時の検証、`FormData` による値の取り出し
- `style.css` … 見た目

## 動かし方

1. ▶ アプリ実行を押すと内蔵の静的サーバーが起動し、出力欄の「🌐 プレビュー」タブにページが開きます
2. 次の順に試します
   - パスワードを打つ → 8 文字に達するまで枠の色と「あと N 文字」が変わる
   - 確認用パスワードを違う値にして「登録」→ ページが遷移せず「パスワードが一致しない」が出る
   - 正しく入力して「登録」→ 「送信される値」に一覧が出て、フォームが空に戻る

## 見どころ

- `input` イベントによるリアルタイム検証（パスワードの長さ、メールに `@` があるか）
- HTML の検証属性では書けない「2 つの欄を見比べる」検証を、送信時に JavaScript で行う
- `FormData` は `name` 属性があり `disabled` でない欄の値をまとめて集める。
  チェックボックスのように同じ `name` が複数あるものは `getAll` で取る
- ラジオボタンは `input[name="work"]:checked` で選ばれているものを指し、チェックボックスの状態は `checked` で読む
- パスワードは画面に出さず `*` に置き換えている
- サーバーへ送るときの `fetch` の形はコメントにだけ書いてあり、実際に送るのは js-fetch 以降の演習で扱います
