# http-curl — curl で HTTP のやりとりを観察する

チャプター 4.1〜4.2「HTTPの基本的な仕組み / 高度な仕組み」の演習です。
curl でリクエストを送り、リクエストライン・ヘッダー・ステータスコードを目で確かめます。
送り先は公開のテスト用サービス `https://httpbin.org` なので、インターネット接続が必要です。

## 主なファイル

| ファイル | 中身 |
|---|---|
| `01_get.sh` | GET。本文だけ / `-i` でステータス行とヘッダー / `-v` で送ったリクエスト / クエリストリング |
| `02_post.sh` | POST（フォーム形式と JSON 形式）・PUT・DELETE |
| `03_status.sh` | 200〜503 の各ステータスコードを返させる。`-L` でリダイレクトを追う / 追わない |

## 動かし方

1. `01_get.sh` を開き、エディタの右上の ▶ 実行を押す
2. 結果は出力欄の「実行結果」に出る。`02_post.sh`・`03_status.sh` も同じように順に動かす

## 見どころ

- `-v` の出力では、`>` で始まる行が送ったリクエスト、`<` で始まる行が受け取ったレスポンス
- httpbin は受け取ったリクエストをそのまま JSON で返すので、`Content-Type` によって
  本文が `form` と `json` のどちらに入るかが分かる
- `-w '%{http_code}'` のように書式を指定すると、知りたい値だけを取り出せる

スクリプトの curl のオプションや URL を書き換えて、もう一度 ▶ 実行で送り直してみてください。
