# css-responsive — レスポンシブと視覚効果を付ける

チャプター 3.3「CSSによるWebページ修飾」の演習です。
商品一覧のページを、メディアクエリで画面の幅に合わせて組み替えます。
あわせて `transition` / `transform` / `box-shadow` / `@keyframes` の視覚効果と、
色や余白を 1 か所で管理する CSS 変数を使っています。

## 主なファイル

- `index.html` … ヘッダー・サイドバー・商品一覧のページ。いまの幅とどのメディアクエリが効いているかを画面上部に出す
  小さなスクリプトだけが入っています（レスポンシブそのものは CSS の機能です）
- `style.css` … いちばん上の `:root` に CSS 変数、いちばん下にメディアクエリがあります

## 動かし方

1. ▶ アプリ実行を押すと内蔵の静的サーバーが起動し、出力欄の「🌐 プレビュー」タブにページが開きます
2. プレビューとエディタの境目をドラッグして幅を変え、画面上部の「いまの幅」とレイアウトの切り替わりを見ます
3. `style.css` を書き換えて保存し、プレビューを再読み込みして結果を見ます

## 見どころ

- 広い画面ではサイドバー + 本文の 2 列、商品は 3 列
- `@media (max-width: 768px)`: サイドバーを本文の上に回して 1 列に積み、商品は 2 列
- `@media (max-width: 480px)`: ナビゲーションとサイドバーを隠し、商品は 1 列
- `meta name="viewport"` が無いと、スマートフォンで縮小表示になる
- CSS 変数: `:root` の `--primary` を変えると、ページ全体の色が一度に変わる。余白は `--space` の倍数（`calc`）でそろえる
- ボタンにマウスを乗せると色と大きさがなめらかに変わる（`transition` + `transform`）
- カードにマウスを乗せると影が濃くなって浮き上がる（`box-shadow`）
- 見出しはページを開いたときに薄く現れる（`@keyframes` + `animation`）
