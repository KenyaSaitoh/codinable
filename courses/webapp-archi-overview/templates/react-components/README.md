# react-components — JSX でコンポーネントを組み立てる

チャプター 10.1.3「Reactの基本的な考え方（JSXとコンポーネント）」の演習です。
`UserCard` コンポーネントを異なる Props で繰り返し使い、親子のコンポーネントツリーを確かめます。

## 主なファイル

| ファイル | 中身 |
|---|---|
| `src/UserCard.tsx` | 主役。Props（name / email / role）を受け取って 1 枚のカードを描く |
| `src/App.tsx` | 親。ユーザーの配列を `map` で `UserCard` に変えて並べる |
| `src/main.tsx` | `index.html` の `#root` に `App` を描画する入口 |

## 動かし方

1. ▶ アプリ実行を押す。初回だけ依存パッケージを自動で入れてから Vite の開発サーバー
   （`http://127.0.0.1:5173`）を起動し、プレビュータブが開く（初回は数分かかることがある）
2. 画面を操作する。ソースを書き換えて保存すると、Vite がすぐに画面へ反映する
3. 終わったら「停止」で止める

## 見どころ

- JSX の波括弧 `{...}` に JavaScript の式を書ける。属性は `class` ではなく `className`
- 配列から描く要素には一意な `key` を付ける（`App.tsx` の `key={user.id}`）
- Props は親から渡される読み取り専用の入力。`App.tsx` の配列にユーザーを足すと、カードが 1 枚増える
