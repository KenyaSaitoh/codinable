# react-form-events — 制御されたフォームとイベント

チャプター 10.1.5「ユーザー操作とサーバー連携（イベント処理）」の演習です。
入力値を State に同期する「制御されたコンポーネント」と、`onChange` / `onSubmit` を扱います。

## 主なファイル

| ファイル | 中身 |
|---|---|
| `src/ProfileForm.tsx` | 主役。名前・メール・担当の入力を State に持ち、`onChange` で同期する。送信時に `onSubmit` を呼ぶ |
| `src/App.tsx` | 送信された値を State に受け取り、「送信イベントの結果」に表示する |

## 動かし方

1. ▶ アプリ実行を押す。初回だけ依存パッケージを自動で入れてから Vite の開発サーバー
   （`http://127.0.0.1:5173`）を起動し、プレビュータブが開く（初回は数分かかることがある）
2. 画面を操作する。ソースを書き換えて保存すると、Vite がすぐに画面へ反映する
3. 終わったら「停止」で止める

## 見どころ

- 各 input の `value` は State の値で、キー入力のたびに `onChange` が State を書き換える
- 送信時は `event.preventDefault()` でページ遷移を止めている。送信してもページは移動せず、
  State から確認表示が作られる
- 名前とメールは `required`、メールは `type="email"` なので、ブラウザーが入力を確かめる
