4 つの領域

content

外から margin（灰）→ border（青の線）→ padding（水色）→ content（白）

width はどこまでを指すか

どちらのカードも width: 240px、padding: 20px、 border: 4px を指定してあるが、画面上の幅が違う。

box-sizing: content-box
（既定）実際の幅は 240 + 20×2 + 4×2 = 288px
box-sizing: border-box
実際の幅は 240px のまま

現代の CSS では、最初に *, *::before, *::after { box-sizing: border-box; } を書いて border-box に揃えるのが定石である。

margin の指定いろいろ

margin: 16px（上下左右）
margin: 8px 40px（上下 / 左右）
margin: 8px auto（左右 auto で中央寄せ）

display による振る舞いの違い

inline inline インライン要素は文章の流れの中に収まり、幅や高さの指定が効かない。

block：横幅いっぱいに広がり、前後が改行される
block：だから縦に並ぶ

inline-block inline-block こちらは横に並びながら、幅と高さの指定が効く。

display: none を指定したので、この文は見えず、場所も取らない

はみ出したとき（overflow）

overflow: visible（既定）。枠からはみ出したまま表示される。ここに長い文章を入れると、 箱の外まで文字があふれる。
overflow: hidden。はみ出した部分は切り捨てられる。ここに長い文章を入れると、 入りきらない分は見えなくなる。
overflow: auto。必要なときだけスクロールバーが出る。ここに長い文章を入れると、 スクロールして読めるようになる。
