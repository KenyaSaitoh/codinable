position と z-index

static（既定）と relative

static：通常の位置に置かれる
relative：通常の位置から右 40px・下 10px ずらした
static：前の要素がずれても、この要素の位置は変わらない

absolute

absolute は、position を指定した最も近い親（ここでは relative を付けた箱）を基準に置かれる。通常の並びから外れるので、 周りの要素はこの要素が無いものとして詰まる。

この箱には position: relative を指定してある。

z-index（重なり順）

数字が大きいほど手前に出る。position が static のままでは効かない。

z-index: 1
z-index: 2
z-index: 3

モーダルダイアログやツールチップは、この仕組みで他の要素より前面に出している。
