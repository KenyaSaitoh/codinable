# css-position — 要素を配置して重ねる

チャプター 3.3「CSSによるWebページ修飾」の演習です。
`position` で「どこに置くか」、`z-index` で「どちらを手前にするか」を決めます。
`static` / `relative` / `absolute` / `fixed` / `sticky` の違いと、重なり順を並べてあります。

## 主なファイル

- `index.html` … 見本のページ。右上の「固定ボタン」、付箋を置いた箱、重なった 3 枚の層、貼り付く見出しがあります
- `style.css` … `position` の値ごとに区切りコメントを付けてあります

## 動かし方

1. ▶ アプリ実行を押すと内蔵の静的サーバーが起動し、出力欄の「🌐 プレビュー」タブにページが開きます
2. プレビューを縦にスクロールして、固定ボタンと見出しの振る舞いの違いを見ます
3. `style.css` の `top` / `left` / `z-index` などを変えて保存し、プレビューを再読み込みして位置や重なりの変化を見ます

## 見どころ

- `static` は既定の配置。`relative` は通常の位置からずらし、周りの要素は詰めてこない
- `absolute` は `position` を指定した親（ここでは `.anchor` に `relative`）の角を基準に置かれる。
  基準にしたい親に `relative` を付け忘れると、画面全体が基準になる
- `fixed` の「固定ボタン」は、スクロールしても画面上の位置（右上）が変わらない
- `sticky` の青い見出しは、画面の上端（`top: 0`）に達すると貼り付いて止まる
- `z-index` の大きいものが手前に来る（`.layer-1`〜`.layer-3` の値を入れ替えると重なり順が変わる）
