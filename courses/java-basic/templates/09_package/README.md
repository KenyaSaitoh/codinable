# 09_package — パッケージとインポート

## 何を学ぶ演習か

同じ名前の `Baz` が 3 つのパッケージにあるときに、インポートでどれが選ばれるかを確かめます。

## 見るファイルと動かし方

ツールバーの **アプリ実行** で、演習一覧で選んだレッスンの main が動きます。ほかの main は、その `.java` を開いてエディタの右上の **ファイル実行** で動かします。実行結果は出力欄の「実行結果」に出ます。

| レッスン | 見るファイル | アプリ実行 | 結果のどこを見るか |
|:--|:--|:--|:--|
| 9.1.2 インポートと名前解決 | `src/main/java/pro/kensait/pkg1/Foo.java` | `pro.kensait.pkg1.Main` | `This is pro.kensait.pkg2.Baz!` |

## 注意

* ソースは `src/main/java/pro/kensait/` の下にあります。原稿の `src/pro/kensait/...` は、この雛形では `src/main/java/pro/kensait/...` です。
