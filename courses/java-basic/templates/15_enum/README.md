# 15_enum — 列挙型

## 何を学ぶ演習か

列挙型の構造、switch と比較、フィールドとメソッドを持つ列挙型、逆引きを確かめます。

## 見るファイルと動かし方

ツールバーの **アプリ実行** で、演習一覧で選んだレッスンの main が動きます。ほかの main は、その `.java` を開いてエディタの右上の **ファイル実行** で動かします。実行結果は出力欄の「実行結果」に出ます。

| レッスン | 見るファイル | アプリ実行 | 結果のどこを見るか |
|:--|:--|:--|:--|
| 15.1.1 列挙型の構造 | `…/lsn_15_1_1/CustomerType.java` | `lsn_15_1_2.Main` | snippet_1 の DIAMOND と 3 |
| 15.1.2 分岐と比較の設計 | `…/lsn_15_1_2/Main_Switch.java`<br>`…/lsn_15_1_2/Main.java` | `lsn_15_1_2.Main` | snippet_2・snippet_3 の会員種別の行 |
| 15.1.3 値と振る舞いを列挙型にまとめる設計 | `…/lsn_15_1_3/CustomerType2.java`<br>`…/lsn_15_1_3/Main.java` | `lsn_15_1_3.Main` | 一般会員とゴールド会員の逆引きの結果 |

`…/` は `src/main/java/pro/kensait/java/basic/` の略です。
