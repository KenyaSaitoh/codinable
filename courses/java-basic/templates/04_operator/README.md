# 04_operator — 演算子

## 何を学ぶ演習か

式の評価の順序、整数の割り算や桁あふれ、比較と論理演算の落とし穴を、snippet で確かめます。

## 見るファイルと動かし方

ツールバーの **▶ アプリ実行** で、演習一覧で選んだレッスンの main が動きます。ほかの main は、その `.java` を開いてエディタの右上の **▶ 実行** で動かします。実行結果は出力欄の「実行結果」に出ます。

| レッスン | 見るファイル | ▶ アプリ実行 | 結果のどこを見るか |
|:--|:--|:--|:--|
| 4.1.1 式の評価の順序 | `src/main/java/Main_4_1.java` | `Main_4_1` | 式の snippet のコード（値はコードのコメントと比べます） |
| 4.1.2 算術演算の落とし穴 | `src/main/java/Main_4_1.java` | `Main_4_1` | snippet_6 の 2.5 |
| 4.1.3 比較と論理演算 | `src/main/java/Main_4_1.java` | `Main_4_1` | 比較と論理演算の snippet のコードと、snippet_22〜snippet_27 のビット演算の 4、13、9、-5、3、-20 |
