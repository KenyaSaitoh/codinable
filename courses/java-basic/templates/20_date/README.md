# 20_date — 古典的な日時クラス、Date and Time API

## 何を学ぶ演習か

`Calendar` と `Date` の問題点と、`java.time` の生成・計算・差分・タイムゾーン・書式を確かめます。

## 見るファイルと動かし方

ツールバーの **▶ アプリ実行** で、演習一覧で選んだレッスンの main が動きます。ほかの main は、その `.java` を開いてエディタの右上の **▶ 実行** で動かします。実行結果は出力欄の「実行結果」に出ます。
