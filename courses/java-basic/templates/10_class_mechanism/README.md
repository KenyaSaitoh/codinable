# 10_class_mechanism — カプセル化とアクセス修飾子、クラスの関連と依存

## 何を学ぶ演習か

アクセス修飾子による公開範囲、アクセサメソッド、双方向の関連、依存の方向を確かめます。

## 見るファイルと動かし方

ツールバーの **▶ アプリ実行** で、演習一覧で選んだレッスンの main が動きます。ほかの main は、その `.java` を開いてエディタの右上の **▶ 実行** で動かします。実行結果は出力欄の「実行結果」に出ます。

| レッスン | 見るファイル | ▶ アプリ実行 | 結果のどこを見るか |
|:--|:--|:--|:--|
| 10.1.1 アクセス修飾子と公開範囲 | `src/main/java/pro/kensait/pkg2/Bar.java` | `lsn_10_2_1.Main_2` | `pro.kensait.pkg2.Bar` のコメントにした【2】【4】（エディターの診断で確かめます。このレッスンのクラスには main がないので、ボタンは `lsn_10_2_1.Main_2` を動かします） |
| 10.1.2 カプセル化とアクセサメソッド | `…/lsn_10_1_1/Person.java` | `lsn_10_2_1.Main_2` | `lsn_10_1_1.Person` のアクセサメソッド（main がないので、ボタンは `lsn_10_2_1.Main_2` を動かします） |
| 10.2.1 関連と方向・多重度 | `…/lsn_10_2_1/Employee.java`<br>`…/lsn_10_2_1/Main_2.java` | `lsn_10_2_1.Main_2` | Alice、Bob、Carol の順の名前 |
| 10.2.2 依存と依存の方向 | `…/lsn_10_2_2/Foo.java` | `lsn_10_2_1.Main_2` | `lsn_10_2_2` の `Foo` と `Bar` の依存（main がないので、ボタンは `lsn_10_2_1.Main_2` を動かします） |

`…/` は `src/main/java/pro/kensait/java/basic/` の略です。
