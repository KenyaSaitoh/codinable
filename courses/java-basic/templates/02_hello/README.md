# 02_hello — Hello, World!、コンパイルと実行

## 何を学ぶ演習か

最小のプログラムを題材に、クラス・mainメソッド・命令文の構造と、「▶ 実行」がまとめて行うコンパイルと実行を確かめます。

## 見るファイルと動かし方

ツールバーの **▶ アプリ実行** で、演習一覧で選んだレッスンの main が動きます。ほかの main は、その `.java` を開いてエディタの右上の **▶ 実行** で動かします。実行結果は出力欄の「実行結果」に出ます。

| レッスン | 見るファイル | ▶ アプリ実行 | 結果のどこを見るか |
|:--|:--|:--|:--|
| 2.1.1 コンパイルと実行の仕組み | `src/main/java/Hello.java` | `Hello` | `Hello, World!` が表示されること |
| 2.1.2 プログラムの構造 | `src/main/java/Hello.java` | `Hello` | `Hello, World!` が表示されること。クラス・mainメソッド・命令文の位置は `Hello.java` の【1】〜【3】で確かめます |
| 2.2.1 エディターと「▶ 実行」の仕組み | `src/main/java/Hello.java` | `Hello` | コンパイルのあとで `Hello, World!` が表示されること |

## 注意

* ソースは `src/main/java/Hello.java` にあります。原稿の `src` フォルダーは、この雛形では `src/main/java` です。新しいクラスもここに作ります。
