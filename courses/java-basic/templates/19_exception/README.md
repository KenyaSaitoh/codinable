# 19_exception — 例外処理、アサーション

## 何を学ぶ演習か

try-catch と例外の伝播、チェック例外、スタックトレース、リソースの後始末、例外チェーン、アサーションを確かめます。

## 見るファイルと動かし方

ツールバーの **アプリ実行** で、演習一覧で選んだレッスンの main が動きます。ほかの main は、その `.java` を開いてエディタの右上の **ファイル実行** で動かします。実行結果は出力欄の「実行結果」に出ます。

| レッスン | 見るファイル | アプリ実行 | 結果のどこを見るか |
|:--|:--|:--|:--|
| 19.1.2 try-catch文と例外の伝播 | `…/lsn_19_1_5/Main_2.java`<br>`…/lsn_19_1_4/case_2/Foo.java` | `lsn_19_1_4.case_3.Main` | `URL生成不可` のメッセージと 0。`Main_2` は入力の行を固定値に書き換えて動かします |
| 19.1.3 チェック例外と非チェック例外 | `…/lsn_19_1_4/case_4/Bar.java` | `lsn_19_1_4.case_3.Main` | `URL生成不可` のメッセージと 0 |

## 注意

* `lsn_19_1_2`・`lsn_19_1_3`・`lsn_19_1_4`（`case_3` を除く）・`lsn_19_1_7`・`lsn_19_2_2` の `Main` はキーボードの入力を読むクラスです。Codinable では入力の代わりに `stdin/<完全修飾クラス名>.txt` の行を順に渡します。最初は例外になる値にしてあるので、正常な値（`10` と `2`、`5`、`abc` など）に書き換えて流し直すと、例外が起きない経路も確かめられます。
* `foo.txt` は雛形の直下にあります。
* ファイル実行は `-ea` を渡さないので、`assert` は無視されます。
