# 18_collection — コレクションフレームワーク

## 何を学ぶ演習か

リスト、セット、マップ、キュー、ソート、不変コレクションを確かめます。

## 見るファイルと動かし方

ツールバーの **▶ アプリ実行** で、演習一覧で選んだレッスンの main が動きます。ほかの main は、その `.java` を開いてエディタの右上の **▶ 実行** で動かします。実行結果は出力欄の「実行結果」に出ます。

| レッスン | 見るファイル | ▶ アプリ実行 | 結果のどこを見るか |
|:--|:--|:--|:--|
| 18.1.3 ハッシュの仕組みとセット | `…/lsn_18_1_3/Person.java` | `lsn_18_1_3.Main` | snippet_3 で Alice が重複して入っていないこと |
| 18.1.4 マップの構造とキー | `…/lsn_18_1_4/Main_Person.java`<br>`…/lsn_18_1_4/Main.java` | `lsn_18_1_4.Main_Person` | `Person [id=102, name=Bob, age=35, gender=male]` |
| 18.1.5 要素の順序とデータ構造の選び方 | `…/lsn_18_1_5/Main_Queue.java` | `lsn_18_1_5.Main_Queue` | snippet_3 の foo |
| 18.2.1 比較の仕組み（ComparableとComparator） | `…/lsn_18_2_1/Person.java` | `lsn_18_2_1.Main_Sort_Person` | snippet_1 の Alice、Carol、Bob の順 |
| 18.2.2 ソートされたセットとマップ | `…/lsn_18_2_2/Main_TreeSet.java` | `lsn_18_2_2.Main_TreeSet` | `[3, 4, 5, 6]` の部分集合 |
| 18.2.3 不変コレクションとビュー | `…/lsn_18_2_3/Main.java` | `lsn_18_2_3.Main` | snippet_1 と snippet_2 の `[foo, bar, baz]` |

`…/` は `src/main/java/pro/kensait/java/basic/` の略です。
