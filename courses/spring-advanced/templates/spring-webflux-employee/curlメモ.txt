### getEmployee（主キー検索。存在する場合は200）
curl -i localhost:8089/employees/1
# HTTP/1.1 200
# {"employeeId":1,"employeeName":"Alice","departmentId":10,"departmentName":"営業部","jobName":"Sales","salary":300000,"entranceDate":"2018-04-01"}

### getEmployee（存在しない場合は404。switchIfEmptyによる切り替え）
curl -i localhost:8089/employees/999
# HTTP/1.1 404

### getEmployees（全件取得）
curl -i localhost:8089/employees
# HTTP/1.1 200
# [{"employeeId":1,"employeeName":"Alice",...},{"employeeId":2,"employeeName":"Bob",...},...]

### queryBySalary（給与範囲をキーに条件検索。Fluxのfilterオペレーター）
curl -i "localhost:8089/employees/query_by_salary?lowerSalary=300000&upperSalary=400000"
# HTTP/1.1 200
# [{"employeeId":1,"employeeName":"Alice",...},{"employeeId":2,"employeeName":"Bob",...},{"employeeId":3,"employeeName":"Carol",...}]

### createEmployee（新規作成。201とLocationヘッダーが返る）
curl -i -X POST localhost:8089/employees -H "Content-Type: application/json" -d {\"employeeName\":\"George\",\"departmentId\":20,\"departmentName\":\"開発部\",\"jobName\":\"Engineer\",\"salary\":280000,\"entranceDate\":\"2023-04-01\"}
# HTTP/1.1 201
# Location: /employees/7
# {"employeeId":7,"employeeName":"George","departmentId":20,"departmentName":"開発部","jobName":"Engineer","salary":280000,"entranceDate":"2023-04-01"}
curl -i localhost:8089/employees/7

### updateEmployee（更新。200）
curl -i -X PUT localhost:8089/employees/2 -H "Content-Type: application/json" -d {\"employeeName\":\"Bob\",\"departmentId\":10,\"departmentName\":\"営業部\",\"jobName\":\"Sales\",\"salary\":360000,\"entranceDate\":\"2015-04-01\"}
# HTTP/1.1 200
# {"employeeId":2,"employeeName":"Bob","departmentId":10,"departmentName":"営業部","jobName":"Sales","salary":360000,"entranceDate":"2015-04-01"}
curl -i localhost:8089/employees/2

### updateEmployee（更新対象が存在しない場合は404）
curl -i -X PUT localhost:8089/employees/999 -H "Content-Type: application/json" -d {\"employeeName\":\"Nobody\",\"departmentId\":10,\"departmentName\":\"営業部\",\"jobName\":\"Sales\",\"salary\":300000,\"entranceDate\":\"2020-04-01\"}
# HTTP/1.1 404

### removeEmployee（削除。204）
curl -i -X DELETE localhost:8089/employees/2
# HTTP/1.1 204
curl -i localhost:8089/employees/2
# HTTP/1.1 404

### stream（SSEストリーミング。1秒間隔で1件ずつ配信される）
# -N（--no-buffer）を付けると、受信した要素が即座に表示され、
# 「全件揃うのを待たずに順次届く」というリアクティブストリームの動きを体感できる
curl -N localhost:8089/employees/stream
# data:{"employeeId":1,"employeeName":"Alice",...}
# （1秒後）
# data:{"employeeId":2,"employeeName":"Bob",...}
# （1秒後）
# data:{"employeeId":3,"employeeName":"Carol",...}
# ...
