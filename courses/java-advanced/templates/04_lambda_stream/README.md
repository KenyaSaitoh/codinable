# 04_lambda_stream — ラムダ式とストリーム

## 何を学ぶ演習か

ラムダ式がどのインタフェースのどのメソッドの実装なのか、いつ実行されるのか、ストリームのパイプラインがどう集約するのかを確かめます（チャプター4.1・4.2）。

## 見るファイル（`src/main/java/pro/kensait/java/advanced/`）

- `lsn_4_1_2`〜`lsn_4_1_7` … `Comparator`、処理を引数で渡す設計、クロージャ（`closure`）、標準の関数型インタフェース、メソッド参照（`Main_5`）
- `lsn_4_2_1`〜`lsn_4_2_4` … 生成・中間操作・終端操作
- `lsn_4_2_5` … `collect()` と売上明細の集計（`Main_Sales`・`Main_Grouping`）
- `lsn_4_2_6` … 並列ストリーム
- `src/main/resources/SALES.csv` … 1 万件の売上明細（売上明細ID、商品名、売上個数）

## ボタンでの動かし方

- 動かしたいクラスをエディタで開き、右上の **ファイル実行** を押します。結果は「実行結果」に出ます。
- ツールバーの **アプリ実行** は、選んでいるレッスンの最初の main を動かします。
- 書き換えて動かなくなったら **↺ 初期化** で配布時の状態に戻せます。

## 結果のどこを見るか

- `comparator.Main_3` は `[USA, Japan, France]` の順に並びます。
- `closure.Main` は `Processor` の中から 140 を表示します。
- `Main_5` はラムダ式とメソッド参照のどちらも `message => Hello, World!` です。
- `lsn_4_2_5.Main_Sales` は `A01 => 236` の形で表示します。
- `lsn_4_2_5.Main_Sales_Slowly` と `lsn_4_2_6.Main_Sales_Slowly` を動かすと、順次と並列の時間の違いが分かります（1 つ 10 秒以上かかります）。
