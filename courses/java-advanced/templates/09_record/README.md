# 09_record — レコード

## 何を学ぶ演習か

レコードが暗黙的に用意するメンバー、値に基づく等価性、コンパクトコンストラクタによる不変条件、レコードパターンを確かめます（チャプター9.1）。

## 見るファイル（`src/main/java/pro/kensait/java/advanced/`）

- `lsn_9_1_1` … `Person`（レコード）、`Person_ofClass`（同じ内容の通常のクラス）、`Main`、`Main_HashSet`
- `lsn_9_1_2` … `Person`（コンパクトコンストラクタ）、`Main`
- `lsn_9_1_3` … `Main`（レコードパターンの `describe()`、`sealed` の `area()`）

## ボタンでの動かし方

- 動かしたいクラスをエディタで開き、右上の **▶ 実行** を押します。結果は「実行結果」に出ます。
- ツールバーの **▶ アプリ実行** は、選んでいるレッスンの最初の main を動かします。
- 書き換えて動かなくなったら **↺ 初期化** で配布時の状態に戻せます。

## 結果のどこを見るか

- `Main_HashSet` は、値が等しい `alice2` の `add()` で `false` を表示し、セットの要素は 3 件のままです。
- `lsn_9_1_2.Main` は検証を通った `Person` の挨拶を表示します。年齢に負の値を渡すように書き換えると、コンパクトコンストラクタの例外で終わります。
- `lsn_9_1_3.Main` は `Bobさんは未成年です`、`Aliceさんは25歳です`、`座標(3, 4)`、`不明なオブジェクト` の順に表示します。
